**READORA** — a smooth PDF reader for Windows, by Imal Madhusanka. Built on PdfCraft v0.21.1.

### Download (Windows 10/11, 64-bit)

| File | |
|---|---|
| `readora-<version>-windows-x64.msi` | **Installer**: READORA in the Start menu, on the desktop and under "Open with" for PDFs |
| `readora-<version>-windows-x64-portable.zip` | **Portable**: unzip, open the folder, run `readora.exe` |

New in READORA: **Create PDF from scanner**, **Sinhala and Tamil OCR** (Tesseract included) and **Export to Excel**.

The files are not code-signed, so Windows may say it protected your PC the first time: choose **More info ▸ Run anyway**.

### සිංහලෙන්

- **`.msi`** එක download කරලා double-click කරන්න. Install වුණාම Start menu එකේ සහ desktop එකේ READORA එනවා.
- හැම PDF එකක්ම READORA එකෙන් open වෙන්න: PDF එකක් right-click › **Open with** › **Choose another app** › **READORA** › **Always**.
- නැත්නම් **`portable.zip`** එක download කරලා unzip කරන්න, `readora.exe` double-click කරන්න.
- පළවෙනි පාර "Windows protected your PC" කියලා ආවොත් **More info › Run anyway** ඔබන්න.
- Scanner එකෙන් scan කරන්න: **File › Create PDF from scanner…**
- Scan කරපු PDF එකක අකුරු (සිංහල, දෙමළ, English) කියවන්න: **Recognize text** › Document language එකට **Sinhala** තෝරන්න.
- Excel එකට: **File › Export › Export to Excel…** (PDF එකේ tables, Excel cells විදිහට එනවා).
- අලුත් version එකක් ආවද බලන්න: **Help › Check for updates**.

This release is rebuilt from the latest code on `main` whenever it changes.
